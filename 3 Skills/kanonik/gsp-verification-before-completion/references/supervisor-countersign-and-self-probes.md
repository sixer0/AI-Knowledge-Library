# Supervisor countersign discipline + self-probe recipes

Condensed from a six-board supervision session (PROMANUAL / GAYA-AHLI / the Unity book / PROMANUAL-V2 / EKASLAP / VISUAL, 2026-10-05..06). Two halves: (A) how to countersign worker claims without becoming the dispatcher; (B) measurement recipes, including probes where MY OWN sensor produced false positives and how each was caught before verdict.

## A. Countersign discipline (supervisor lane)

1. **Redeliver guard FIRST.** Kanban notifications duplicate. Before writing any verdict, grep the card for your own marker: `hermes kanban show <id> | grep -c "Countersign pengawas"`. If >=1 and the new result text matches what you already measured, post NOTHING. Silent no-action on redeliver is a verified behavior, not laziness.
2. **`completed` is a claim, not a fact.** Verdict only from artifacts opened on disk this turn: target file, source file, instrument, paperwork. `blocked`/`timeout`/`gave up` get an interim note (phase verdict: what is frozen-good on disk, what remains, bekal for next run), never a blind re-dispatch.
3. **Numbers = tool print of THIS turn.** Never quote a figure from another agent's report or from memory into a verdict. If you drafted a result before the live run finished, rewrite the draft from the actual print (this session caught my own draft claiming "VERDICT PASS" before my scan had finished - fixed pre-send; lesson: claims only from prints already captured).
4. **Corrections to published trails go in a SEPARATE comment** (never edit old comments), and the corrected text must be censored against the PUBLISHED text, not the draft file. Applies to corrections of corrections. A wrong inference from a stale board census (e.g. "closed silently" when the card simply predated your census) gets retracted the same way, with the correct print.
5. **Do not load raw per-dimension judge scores into a supervisor countersign while another judge is still running** - the countersign becomes a cross-judge leak channel (observed live: a reviewer disclosed reading scores from my earlier countersign). Predicates + bases only.
6. **A tool-invocation claim inside an artifact is verified by reading the invocation header or re-running the tool.** "scanner PASS on X" printed in a report is unverified until you see argv (file argument vs `--text <path-string>`) or run it yourself. This was the root of a mission-level finding: the "scan" had measured the path string, not the document body, and a release verdict built on it had to be re-based.
7. **Fixes must not silently relax the instrument.** When a gate fails on a known-genre conflict, the two legitimate routes are: named edit of the artifact, or an explicit registered ruling (channel/closed-vocab with fixture). Quiet threshold-widening = defect; the verifier should name which route was taken.
8. **Pin two-era discipline:** when an object you previously countersigned changes pin (healing/fix cards), state in the new verdict which byte each verdict stands on, and require downstream to re-run instruments over the NEW pin ("don't inherit era-old results"). Keep `_arsip/` complete per revision; if a verdict-pinned byte is missing from the archive, that is a critical audit-trail finding, and a byte-exact reconstruction (assert-to-pin) restores it.
9. **Self-corrections belong in the trail.** Supervisor sanggahan that fired this session: (a) a DOCX countersign verified idempotency/tail/media/rels but never "Word can open it" - the zipfile/python-docx sensors are as tolerant as the gate was; OPC-integrity checks now mandatory; (b) endorsing a fleet SOUL block containing an unverified scanner-PASS claim without testing the invocation. Both posted as explicit retraction comments. A verdict correct-for-what-it-measured but incomplete-in-scope says so.
10. **Timeout/gave-up interim note format:** phase verdict (which sub-artifacts landed on disk with pins, e.g. register JSON + figures PNG/SVG before the bridge window killed the run), "no state damaged / no partial-final-named artifacts", bekal list for the retry (frozen assets to reuse, official dependency command), and the escalation rule: second timeout of the same heavy-builder card = split per-bab, don't burn a third full slot on the same recipe.

## B. Artifact sensor recipes (verified) + false-positive traps (mine)

### DOCX package (zipfile, no python-docx needed)
- **OPC hard checks** (the class that made a Word-valid-looking file "corrupted"): (1) rel-Id uniqueness - `re.findall(r'Id="([^"]+)"', rels)` must have zero duplicates; a carry-image reusing `rId46` collided two targets. (2) every `[Content_Types].xml` Override must point to a part that exists (ghost overrides found: 89-90). (3) REAL open probe: `win32com` `Documents.Open(ReadOnly=True)` + `ComputeStatistics(2)` page count. zipfile/python-docx tolerate all three defects silently.
- **Anchor integrity:** `<w:bookmarkStart w:name>` census vs `<w:hyperlink ... w:anchor>` census; every internal anchor must resolve to a bookmark (anchor-without-target = 0). Known Word-exporter defect: custom bookmarks inside TOC-source paragraphs are DESTROYED on TOC regeneration (correlation 487/487; survivors only in non-TOC paragraphs) - detect by comparing builder-era docx vs post-Word copy; PDF GoTo census by page-range confirms it downstream (all GOTO inside TOC pages = body links dead).
- **URL/DOI cut:** external rel Targets with parentheses (`doi.org/10.1002/(SICI)...`) get truncated by naive URL parsers; validate Target FORMAT (balanced parens) before HTTP probe. Compare against the previous EDITION as a comparator - edition-comparison is the only way this class gets caught.
- **Edition label two-way gate:** on the published layer, `(Edition N)`=1 and `(Edition N-1)`=0; audit-layer occurrences are separate - classify per-line against meta-block bounds before calling a residue a defect.
- **Tail check:** last ~200 chars of flattened text must reach the real closing line (prevents quadratic-truncation partials posing as finals).

### PDF (PyMuPDF)
- Page count, `get_text()` sum (cross-cetakan content-drift yardstick: same char total across reprints = content unmoved; delta should equal exactly the named inserted paragraph), `get_links()` by kind: LINK_URI list -> truncated = regex `\([^)]$` per uri; LINK_GOTO census + page-range split separates TOC-navigation from body jumps.
- **screen/print pair convention:** bytes DIFFER (metadata/timestamp), text must be IDENTICAL page-by-page. Test both directions; "byte-identical pair" would be the wrong expectation.
- Clause-presence check for published-register: iterate pages, search exact sentence, record page number (proves a late register edit actually reached print).

### Self-probe traps hit this session (each became a pre-vonis correction)
- **CSV delimiter:** inventory CSVs here are PIPE-delimited; `csv.DictReader(open(...))` default comma produced "1558 empty rows". Read the header line first.
- **JSON manifest keys:** probe printed "56 files missing" because I guessed columns `png`/`sha256_png` that are only partially filled; canonical keys were `path`/`sha256`. Print `sorted(items[0].keys())` before any census.
- **XML attribute order:** a `<w:hyperlink` regex assuming `w:anchor` position undercounted 722->496; capture the whole start-tag then search attributes inside it.
- **Path census regex:** paths with spaces ("James F. Kurose...") and trailing backticks produce fake "missing" hits; treat a 0-hits or all-missing census as sensor-bug-suspect before artifact-guilty.
- **`--out` semantics:** some CLIs treat the output arg as a DIRECTORY (writes several files inside); `cmp` against it as a file yields false "BEDA/missing".
- **CRLF byte math:** disk bytes != LF-normalized claim bytes; sha16 content-match + (byte-diff == CR count) = consistent; record both conventions instead of calling it a mismatch.
- **Shell guards:** `&` inside inline command text is rejected - write payload to a temp file and pass `"$(cat file)"`; apostrophes in long comments break quoting the same way. Fix local typos in the temp file with `sed` BEFORE posting, not via posted-correction cycles. Also: a write_file of a long one-line verdict can silently truncate - `wc -c` + `tail` the file before posting, and grep the POSTED comment for the corrected phrase after any fix round.
- **Hang guard:** chaining scanner + extra one-liner in one terminal call risked a timeout-block; run one clean command per claim you need printed.

### Board census before any map claim
`hermes kanban list | awk '/TENANT/{if(/done/)d++; else if(/running/)r++; else if(/blocked/)b++; else if(/ready|todo/)t++} END{print d,r,b,t}'` - run as the LAST step before sending a verdict and put the print into the verdict text (maps written from an earlier census go stale mid-turn; several correction comments this session existed only because a map aged between draft and send).
