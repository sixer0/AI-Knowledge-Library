# First-Arrival Validation Form (D-06)
Filled during the first real DD run against this procedure. One row per
incident; vendor anonymity optional. This form captures only what the first run
actually showed: its limitation is that a single engagement cannot expose every
failure mode of the procedure, so an empty register is recorded explicitly as
zero incidents per stage rather than left unwritten. End the form with incident
counts across all 7 stages. This form is the input for standard Rev B.
