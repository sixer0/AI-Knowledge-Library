# EXPO26 Collector Runbook (validated 2026-09-02, cards C07-C16)

## Trigger
Kanban card titled "EXPO26-Cxx: Kumpul B<n> <REGION>" writing b*-*/expo-raw.csv under
C:/Users/TRIAL/workspace/gsp-hermes/workspace/collection/expo2026/.

## Proven pipeline (in order)
1. Read SCHEMA.md first (17 core columns + Catatan = 18). Copy search_fast.py from a prior
   workspace (t_8d3e6da2) into the card dir; run with `uv run --with ddgs python search_fast.py queries.json hits.jsonl`
   in BACKGROUND (~5s/query; 50 queries ~5 min). Only backend bing works.
2. web_search builtin is NOISY/JUNK on this host (confirmed defect C05/C11/C13) - do not use.
3. Build sites.json (~35 known brand URLs per wave) and run probe.py (parallel urllib, regex
   MONTH-day-year dates + exhibitor/visitor numbers). 3 waves typical. urllib reaches many
   sites that web_extract fails on (ignite, moscone) and vice versa (sc26, nvidia - use web_extract).
4. Filter hits with frag*.py helpers (regex over hits.jsonl title/body for dates and scale
   numbers). NEVER `python -c` inline in terminal - blocked by command guard; write .py files.
5. Write CSV only to own card dir. Header must equal SCHEMA 17 + Catatan. Bucket_asal/Kartu_asal
   per card. Status vs 2026-09-02 cutoff. Upcoming rows with numbers need ~ + Catatan
   'est-dari-edisi-sebelumnya'. Empty Bukti_ukuran is legal when unpublished - never invent.
6. Write check_cXX.py deterministic self-check (copy pattern from check_c16.py in b7-usa,
   17 checks incl. naturalization scan) and natscan.py for catatan.md. Run, show output, then claim.
7. Finish: kanban_comment full verification report, then kanban_complete with artifacts + metadata
   (klaster_tags, status_rows, temuan_conflik, sisa_kerja_opsional).
   kanban_complete gotcha (t_2ab794f5): the kernel validates EVERY path string it finds, including
   relative paths nested in metadata - "collection/expo2026/..." fails with "declared scratch
   artifact is unavailable". Put artifacts=[absolute paths inside the card's scratch workspace]
   (copy files there first) and reference the shared-workspace contract location as free text
   only, never as bare relative paths in metadata.

## Pitfalls
- Empty optional columns: count commas! Penyelenggara AND Negara_peserta both empty = TWO
  consecutive empty fields before Bukti_ukuran. One missing comma silently shifts every later
  column; dbg by zipping header->row and printing per-field (check catches it only via enum/
  Sumber checks).
- Official homepages often already show NEXT edition (2027); current-edition dates then come from
  press releases, venue calendars (moscone.com/events/<slug> is gold), or registrant subdomains.
  Record conflict in Catatan.
- Terminal blocks `python -c`; always write helper .py files.
- process(wait) clamps to 60s here; poll repeatedly instead of long waits.
- Budget notice arrives ~mid-run: at that point STOP discovery, mandatory writes only
  (CSV + check + catatan + comment + complete).
- Known-good scale sources: vendor press releases, swapcard event pages, venue listing pages.
