# Supervisor recipes — delta-reconstruction, constant-only re-pin, ceiling readings, denominasi register, self-sensor failures (2026-10-08, papan VCTL-1007 / GAYAMANUAL-1007 / PSIKOTES-1008)

Condensed from countersign turns where the supervisor's own probe or the worker's instrument produced a reusable technique. All numbers below were re-measured on disk by the supervisor that turn.

## 1. Delta-reconstruction proof (VCTL V1-R, strongest single-cell evidence seen)
Claim "the fix changed exactly one cell" is proved cryptographically, not narrated:
take the NEW byte, programmatically remove the claimed delta (e.g. strip `"; Treemap chart"` from catalog.csv), and hash the reconstruction. If the result equals the OLD pin (`88ffc2f4`/90.506 B == prior verdict pin, exact), the delta is proven to be exactly that cell — no side effects, no silent regeneration.
Recipe: `A2 = sha16(reconstruct(new_byte)); assert A2 == old_pin`. Generalizes to any "minimal edit" claim (1-cell, 1-line, 1-file). Red-green fixture discipline elevated to byte-forensics.

## 2. Re-pin without editing the verdict instrument (VCTL V3)
When the input pin ages out (manual rebuilt after the gate was pinned), do NOT mutate the gate script's logic. Copy it, change ONLY constants (PIN_*, LOG_PATH, RUN2_DIR, banner), and prove the claim with your own diff: `difflib` between old and new script must show only constant lines (measured: 8 lines, all constants). Print the re-pin rationale as a comment on the constant line so the era is explicit. Alternative (wrong): forcing CHECK-0 to pass by loosening.

## 3. Gate on frozen replica while another writer is live (VCTL V1-R)

Related discriminative-power proof: two blind seats independently produced identical D3 aggregate 3,73 on the same byte — rubric separation validated empirically, not claimed.
