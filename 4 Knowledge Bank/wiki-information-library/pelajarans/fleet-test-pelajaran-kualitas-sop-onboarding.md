# Pelajaran kualitas SOP: gap SOP Penerimaan Klien Baru GSP (draf) dan standar perbaikannya


Penilaian kualitas sample_sop.md (SOP Penerimaan Klien Baru GSP — DRAF, 18 baris / 566 byte) [sumber — review.md hal. 1-6; assessment.md hal. 1-2]:
Skor rata-rata 2/5 (document-reviewer), 2,75/5 (document-analyst); F.1 internal quality 4/10 PASS; F.3 information completeness 1/6 PASS; tidak layak distribusi sebelum revisi besar.

Temuan HIGH: (1) tidak ada SLA — tanpa target waktu untuk satu pun langkah; (2) tidak ada alur eskalasi — diakui dokumen sendiri (verifikasi macet > 3 hari kerja); (3) kriteria "dokumen lengkap" tidak didefinisikan dan sistem tidak disebut namanya.
Temuan MEDIUM: tidak ada bagian Tanggung Jawab (RACI); tidak ada dokumen control (nomor, versi, owner, klasifikasi, riwayat revisi); tidak ada penanganan pengecualian; tidak ada referensi kebijakan/regulasi (relevan: UU No. 27 Tahun 2022 — Pelindungan Data Pribadi, karena SOP memproses data pribadi klien).

Rekomendasi prioritas: tambah SLA per langkah (mis. verifikasi <= 2 hari kerja); jadikan alur eskalasi bagian formal bernomor (pemicu > 3 hari kerja, PIC tiap level, jalur penyelesaian); definisikan checklist lampiran "dokumen lengkap"; sebut nama sistem/CRM; tutup loop dengan langkah verifikasi ulang; tambah RACI; pindahkan Definisi sebelum Prosedur; tambah dokumen control header; audit trail + kebijakan akses data klien.

Kelas bukti: sekunder (analisis reviewer/analyst terhadap dokumen draf; bukan penilaian dokumen final).
