# Rubrik readiness skill 3 level (Production-Ready/Needs-Review/Draft) dengan kode defisiensi D1–D6

Penilaian readiness memakai rubrik 3 level: **Production-Ready** (frontmatter name+description+category, `## Role` eksplisit, workflow bernomor, Completion Gate eksplisit), **Needs-Review** (SKILL.md fungsional tetapi kehilangan ≥1 elemen), **Draft** (minimal/placeholder). Enam kode defisiensi: D1 missing category, D2 missing Role, D3 workflow tidak lengkap, D4 tanpa Completion Gate eksplisit, D5 template-identik, D6 missing tags/related_skills.
