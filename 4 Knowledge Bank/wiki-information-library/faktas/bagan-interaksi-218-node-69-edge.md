# Bagan Interaksi Antar Skill: 218 Node, 69 Edge, 4 Tipe

Bagan interaksi antar skill ekosistem GSP: **218 node, 69 edge, 4 tipe
interaksi** (bagan_interaksi_skill.md; interaksi_skill.json; contract doc
2026-08-24-bagan-matriks-skill.md).

- **Node:** skill (warna = kategori). Universe 218 = 130 registry/kanonik +
  88 per-profil.
- **Edge:** referensi silang dari body SKILL.md & frontmatter → 69 edge.
- **4 tipe interaksi:**
  1. `related`: deklarasi `related_skills` di frontmatter (mis. docx ↔
     pdf/xlsx/powerpoint).
  2. `mention`: skill dirujuk dalam body (umumnya dalam backtick / contoh
     perintah).
  3. `gsp-ref`: referensi skill `gsp-*` dalam body (pola khas fleet GSP).
  4. `shared-context`: dua skill dimuat bersama oleh profil yang sama
     (ALWAYS/ON DEMAND) → lihat matriks pemetaan.
- Statistik edge (Ringkasan xlsx): bertipe related 0; mention/backtick 57;
  gsp-ref 17 (jumlah 74? data mentah; verifikasi dari JSON 69 edge unik,
  bobot gabungan).
- Visualisasi: bagan_interaksi_skill.png (717 KB, 218 node/69 edge, legenda 20
  kategori) + versi Mermaid fokus 35 hub di bagan_interaksi_skill.md.
