# Registri 12 identitas skill EKAS lintas versi (A1-A5)

Korpus EKAS memuat **12 identitas skill** yang terdeteksi lintas versi, terbagi dalam 5 kelompok:
A1 (5 skill angka dibangun T11–T12), A2 (3 skill perancang pre-existing), A3 (2 skill DEMS
terpasang tanpa rujukan), A4 (1 skill dicanangkan: onvif-interop), A5 (1 lainnya: excel-master).
Inventaris ini disusun dari scan 270 file korpus EKAS (`gsp-ekas/model-lokal/`) — sumber utama
CHANGELOG.md (T1–T21), GAP-ACQUISITION-PLAN.md, SOURCE-UPDATE-PROCEDURE.md,
TEMPLATE-BERITA-ACARA.md, README-ekspor.md, dan knowledge cards (INVENTARIS-SKILL-PANDUAN-EKAS.md,
baris 12). 8 file `DOCUMENT-CONTROL.md` di korpus BUKAN skill, melainkan berkas document-control
(baris 57). Tujuan inventaris: memetakan seluruh artefak skill/panduan/prosedur/templat/alat
lintas versi agar tidak ada yang terlewat saat dibangun ulang/dipakai (baris 14).

## Bukti

- 12 identitas skill terdeteksi di korpus, kelompok A1–A5 (sumber, bagian A, baris 18–57).
- Disusun 24 Agustus 2026 oleh Brahma (orchestrator) dari scan 270 file korpus (sumber, baris 12).
- document-control (8 file) bukan skill — berkas DOCUMENT-CONTROL.md (sumber, baris 57).
- Tujuan: peta menyeluruh agar tidak ada artefak terlewat saat rebuild (sumber, baris 14).
