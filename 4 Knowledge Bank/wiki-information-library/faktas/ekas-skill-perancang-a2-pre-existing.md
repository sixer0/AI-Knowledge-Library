# Tiga skill perancang EKAS pre-existing (cctv/perimeter/hw-sw)

Tiga skill perancang EKAS sudah ada sebelumnya (pre-existing di Mac) dan dirujuk korpus:
(1) **cctv-system-designer** — perancang VSS; disebut di CHANGELOG T12 "tetap memegang
perancangannya"; bahan rujukan TEMPLATE-BERITA-ACARA.md §2–3 dan resume Damjanovski/Szeliski
(`05_DOMAIN-KNOWLEDGE/VIDEO-SURVEILLANCE/`), (2) **perimeter-security-designer** — perancang
keamanan perimeter (sumber: CHANGELOG T12), (3) **hw-sw-config-master** — konfigurasi
hardware/software (sumber: CHANGELOG T12). Ketiganya termasuk kandidat build ulang opsional
untuk fleet Hermes gsp-* (bagian D, baris 90).
