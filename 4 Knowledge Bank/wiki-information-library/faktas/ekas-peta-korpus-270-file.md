# Peta isi korpus EKAS - 270 file per map (00-90 + dibangkitkan)

Peta isi korpus EKAS (270 file, `gsp-ekas/model-lokal/`) per map: `00_START-HERE/` (README,
EKAS-SYSTEM-MAP, DOCUMENT-CONTROL, CHANGELOG, TEMUAN-UJI-COBA-P00 — ✅ ada); `01_GOVERNANCE/`
(R1–R5, AUTHORITY-STATUS, ASSURANCE-WORKFLOW, ASSURANCE-GATES, AI-USAGE-POLICY,
SOURCE-UPDATE-PROCEDURE — penerus PROSEDUR-TAMBAH-BUKU); `02_REGISTERS/` (8 CSV+md:
MASTER-REFERENCE, GAP-REGISTER, GAP-ACQUISITION-PLAN, REQUIREMENT, DESIGN-DECISION,
CALCULATION, TEST, EVIDENCE, ASSET-REFERENCE + R3/R4-STATUS + INTAKE); `03_SOURCE-VAULT/`
(22 laci + `_ISI.md` manifest; 160 PDF hanya di paket `lengkap/`); `04_KNOWLEDGE-CARDS/`
(61 kartu REF-*.md); `05_DOMAIN-KNOWLEDGE/` (30 resume buku + 12 RANTAI-JAMINAN.md);
`06_ENGINEERING/` (KATALOG-RUMUS, ASUMSI-BAKU, contoh P00); `07_VERIFICATION-VALIDATION/`
(TEMPLATE-BERITA-ACARA 8 jenis uji, ITP/SAT/FAT/NCR, ambang terima); `08_EVIDENCE/` `09_HANDOVER/`;
`10_TEMPLATES/` (TPL-00…TPL-09); `90_TOOLS/` (16 skrip: OCR, bangun katalog/paket/struktur,
migrasi, triase, periksa_ekas.py, bangun_daftar_skill.py); plus artefak dibangkitkan
(04-daftar-rujukan-lengkap.md, _ISI.md per laci, INTAKE-QUEUE.csv/INTAKE-RINGKAS.md).

## Bukti

- Korpus = 270 file, scan `gsp-ekas/model-lokal/` (sumber, baris 12).
- Tabel peta map 00_START-HERE … 90_TOOLS + *dibangkitkan* (sumber, bagian B, baris 61–76).
- 02_REGISTERS: 8 CSV+md dengan daftar register (sumber, baris 67).
- 03_SOURCE-VAULT: 22 laci + _ISI.md manifest; PDF 160 hanya di paket lengkap/ (sumber, baris 68).
- 04_KNOWLEDGE-CARDS: 61 kartu REF-*.md (sumber, baris 69).
- 05_DOMAIN-KNOWLEDGE: 30 resume buku + 12 RANTAI-JAMINAN.md (sumber, baris 70).
- 90_TOOLS: 16 skrip (sumber, baris 75).
