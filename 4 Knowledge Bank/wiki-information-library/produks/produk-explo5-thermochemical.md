# OZM EXPLO5 Thermochemical Computer Code — spesifikasi & lisensi

## Ringkasan
EXPLO5 dari OZM Research (Czech Republic) adalah thermochemical computer code untuk memprediksi sifat energetik bahan berbahaya: kecepatan detonasi, tekanan, energi, perilaku termodinamika campuran multikomponen, serta parameter performa bahan peledak, propelan dan piroteknik. Versi terbaru saat dokumen: V8.01.01 dengan kemampuan batch calculation.

## Fakta & provenans
- Fitur utama: 6 mode running; database reaktan/produk yang dapat diperluas; perhitungan berdasarkan teori Chapman-Jouguet; model detonasi non-ideal Wood-Kirkwood; koefisien EOS Jones-Wilkins-Lee (JWL); batch calculation (puluhan-ratusan kalkulasi otomatis) [PENAWARAN_PT_GSP.pdf — lampiran EXPLO5 datasheet]
- EOS yang digunakan: BKW, BKW-M, Exp-6 (produk gas detonasi); ideal gas & virial (produk pembakaran); Murnaghan (produk kondensat) [lampiran]
- Menangani 52 elemen: C, H, N, O, Al, Cl, Si, F, B, Ba, Ca, Na, P, Li, K, S, Mg, Mn, Zr, Mo, Cu, Fe, Ni, Pb, Sb, Hg, Be, Ti, I, Xe, U, W, Sr, Cr, Br, Co, Ag, Zn, Sn, Bi, Cs, Hf, Ge, Nb, Ta, Yb, Y, V, Ar, He, Cd, Ce [lampiran]
- Kepatuhan standar: EN 13631-15:2005 (explosives for civil uses — perhitungan sifat termodinamika) [lampiran]
- Lisensi: Single-User Machine-Locked (HWFP + SL key), Single-User Portable (SL+HL key via USB), Multi-User Network (server license + pool client); behavior: Trial (~30 hari), Perpetual (SL key diperpanjang tahunan otomatis; maintenance opsional) [lampiran]
- Syarat sistem: Windows 11/10/8.1/8/7 SP1 (x86/x64); .NET Framework 4.6.1+; Office 2007+; prosesor 2.0 GHz+; RAM 4 GB; disk 100 MB; resolusi 1440x900+; USB 2.0; TIDAK dapat berjalan di virtual machine / Remote Desktop Services [lampiran]
- Default: 1 tahun free upgrade & maintenance; training online 4+4 jam opsional [lampiran]
