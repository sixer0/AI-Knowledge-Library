# OZM EXPLO5 Thermochemical Computer Code — kode termokimia bahan energetik (V8.01.01, batch calculation, EN 13631-15:2005)

Spesifikasi EXPLO5TM — thermochemical computer code oleh OZM Research s.r.o (Blžovice 32, 538 62 Hrochv Týnec, Czech Republic), dari datasheet lampiran penawaran (ver. 2025-1). Klasifikasi: spesifikasi produk dari materi pabrikan — verifikasi ulang saat dipakai mengikat.
- Fungsi: memprediksi sifat energetik zat berbahaya — kecepatan detonasi, tekanan, energi; perilaku termodinamika campuran multikomponen; parameter performa bahan peledak, propellant, komposisi piroteknik.
- Metode: teori Chapman-Jouguet (CJ); koefisien persamaan keadaan Jones-Wilkins-Lee (JWL) dari data ekspansi isentropik; model detonasi non-ideal Wood & Kirkwood + kinetika bergantung tekanan; minimasi energi bebas; EOS: BKW, BKW-M, Exp-6 (produk gas detonasi), ideal gas & virial (produk pembakaran gas), Murnaghan (produk terkondensasi).
- Versi V8.01.01: perhitungan batch (puluhan–ratusan perhitungan otomatis dari daftar batch); komposisi dapat didefinisikan fraksi massa, volume, atau molar.
- Basis data: reaktan & produk; 52 unsur (C, H, N, O, Al, Cl, Si, F, B, Ba, Ca, Na, P, Li, K, S, Mg, Mn, Zr, Mo, Cu, Fe, Ni, Pb, Sb, Hg, Be, Ti, I, Xe, U, W, Sr, Cr, Br, Co, Ag, Zn, Sn, Bi, Cs, Hf, Ge, Nb, Ta, Yb, Y, V, Ar, He, Cd, Ce); komponen baru dapat ditambah (rumus kimia, panas pembentukan, densitas).
- Standar: memenuhi EN 13631-15:2005 (Explosives for civil uses — High explosives — Part 15: Calculation of thermodynamic properties).
- Lisensi: tipe Single-User Machine-Locked / Single-User Portable (SL+HL keys) / Multi-User Network (server + pool klien); perilaku Trial (30 hari) / Perpetual (SL term extendable, diperbarui otomatis tahunan; maintenance opsional). Default 1 tahun upgrade & maintenance; pelatihan daring 4+4 jam.
- Persyaratan sistem: Windows 11/10/8.1/8/7 SP1 (x86/x64); .NET Framework 4.6.1+; Office 2007+; fisik (tidak jalan di VM / RDS); 2,0 GHz; 4 GB RAM; 100 MB disk; resolusi 1440×900+; USB 2.0.
- Paket penawaran (Rp 4.500.000.000, belum PPN): EXPLO5 V8.01 + EX5-UM3 (3 tahun) + EX5-UM4X ×6 + X5-USB-HW + PC desktop (i7/32 GB/1 TB/24") + training 2 × 4 jam telekonferensi.
