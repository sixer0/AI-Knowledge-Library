# Panduan Kualitas Dokumen GSP — Kerangka Keputusan & Pra-Penulisan

## Ringkasan
Standar pemilihan tipe dokumen, audiens, dan tier distribusi SEBELUM menulis, plus 5 checkpoint wajib dan template spec analysis 12 field. Adaptasi Document Quality Standards v1.3 (Module A, B, E, J) untuk GSP orchestration.

## Bukti (sumber: document-quality-improvement-guide.md, Bagian 1–2)
- Decision tree 8 tipe dokumen: Research Document, Information Mapping, Business Document, Technical Document, Operational Document, Planning Document, Analytical Document, Educational Document; default General Report → struktur Research Document (Bagian 1.1).
- Matrix audiens → kedalaman: Executive 1–2 halaman, Management 5–10, Engineer 10–20, Developer 15–30, Researcher 20–50, Customer 3–10, General public 2–5; pemetaan kata kunci request → audiens (mis. "untuk direksi" → Executive) (Bagian 1.2).
- Independence tier 1–6: Internal Use (relaxed), External Distribution (full), Customer Delivery (full + professional), Regulatory Submission (strictest + audit trail), Executive Presentation (depth-controlled), Public Publication (strictest external, fully standalone); tes cepat tier (Bagian 1.3).
- 5 checkpoint pra-delegasi: CP-1 tipe dokumen; CP-2 audiens + kedalaman; CP-3 independence tier; CP-4 spec analysis (WAJIB untuk Creation, DELTA untuk Modification, SKIP default Conversion/Translation); CP-5 bahan mentah tersedia + unknowns dinyatakan (Bagian 2.1).
- Spec analysis 12 field: content map, structure/hierarchy, formatting, tone/voice, depth, audience, independence tier, anti-AI guidance, humanizer, narrative naturalness, design flexibility, quality gate; memo/surat/email cukup field 1–7, dokumen formal lengkap wajib 12 (Bagian 2.2).
- Alur cepat: identifikasi audiens → kedalaman → tier → struktur berlapis untuk audiens campuran (Executive Summary + Main Body + Appendices) (Bagian 1.2, 2.3).

## Catatan
Kelas bukti sekunder (panduan internal GSP). Aturan ini standar normatif — bukan klaim fakta eksternal; angka target (halaman, kata) adalah guideline, bukan ukuran terverifikasi eksternal.
