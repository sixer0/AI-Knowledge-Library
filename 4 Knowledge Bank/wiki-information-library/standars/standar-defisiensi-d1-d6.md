# Standar taksonomi defisiensi D1–D6 untuk penilaian readiness skill Hermes

Taksonomi defisiensi readiness skill: **D1** missing `category` frontmatter (Low); **D2** missing `## Role` / hanya implisit (Low); **D3** workflow steps hilang/tidak lengkap (Medium); **D4** tanpa Completion Gate checklist eksplisit (Low); **D5** konten template-identik tanpa kustomisasi (Medium); **D6** missing tags/related_skills (Low). Dapat dipakai sebagai rubrik audit skill Hermes/GSP untuk menentukan prioritas perbaikan (P1: D1 → P2: D3/D5 → P3: D2/D4 → P4: D6). [R — 99_implementation_report.md §4.1, hal. 227–236]
