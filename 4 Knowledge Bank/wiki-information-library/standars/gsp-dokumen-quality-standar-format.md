# Panduan Kualitas Dokumen GSP — Standar Format Output

## Ringkasan
Standar format dokumen formal GSP: format angka Indonesia, hierarki heading, tabel, cross-reference, cover page, peta gaya DOCX, dan red flags formatting yang harus dihindari.

## Bukti (sumber: document-quality-improvement-guide.md, Bagian 4)
- Format angka Indonesia: ribuan titik (65.366.315.300 — bukan 65,366,315,300), desimal koma (63,44% — bukan 63.44%), rentang en-dash (2027–2028), approximate ± (± 19.000 meter), currency (Rp 65,44 miliar, US$1,1 miliar, €30 juta) (Bagian 4.1).
- Exact vs approximate: data kontrak/kuitansi exact; estimasi pra-RAB band ("Rp 23–54 miliar"); ukuran fisik ±; statistik industri "sekitar" (Bagian 4.1.2).
- Heading hierarchy: H1 "BAB X - TITLE" ALL CAPS, H2 "X.Y" sentence case, H3 "X.Y.Z" sentence case, H4 bold sentence; jangan lompat level; default per tipe konten (memo boleh sederhana) (Bagian 4.2).
- Tabel: numbering "Tabel X.Y. Caption", header bold, teks kiri angka kanan, hanya untuk data terstruktur bukan narasi (Bagian 4.3).
- Cross-reference: internal (pada Bab X, lihat §X.Y, Tabel X.Y, Gambar X.Y, Lampiran X); eksternal regulasi "Perpres 16/2018", standar "FM 4-30.13", kontrak "KTR/24/II/KP/2026"; citation inline/numbered [N]/footnote — pilih satu format konsisten (Bagian 4.4).
- Cover page template: [NAMA PERUSAHAAN]/[JENIS DOKUMEN]/[JUDUL]/nomor dokumen [nomor]/[inisial]/[kode]/[bulan romawi]/[tahun] (contoh 003/GSP/KT/VII/2026); default formal — memo boleh tanpa cover (Bagian 4.5).
- DOCX style map: serif, H1 14–16pt ALL CAPS bold, body 11–12pt justified, line spacing 1.15/1.5, margin kiri 3 cm (binding), A4; header (dokumen/nomor/klasifikasi) + footer (perusahaan, halaman X dari Y, tanggal) (Bagian 4.6).
- Red flags formatting: Title Case di heading bahasa Indonesia, excessive boldface, pola "**Bold**: deskripsi", emoji di konten formal, subject line di non-email (Bagian 4.7).

## Catatan
Kelas bukti sekunder. Standar normatif internal GSP.
