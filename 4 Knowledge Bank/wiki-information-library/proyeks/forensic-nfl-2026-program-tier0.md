# Program GSP-NFL-2026/T0 — Kajian Komprehensif Laboratorium Forensik Utama Nasional (Tier-0)

Program nasional Laboratorium Forensik Utama Nasional — konfigurasi inti prioritas (Tier-0). Kode program GSP-NFL-2026/T0; dokumen induk Kajian Komprehensif 015/GSP/PT/VII/2026 versi 1.1-A, terbit 26 Juli 2026; klasifikasi INTERNAL — PRE-DECISIONAL (bukan penawaran/komersial; seluruh harga indikatif wajib rekonfirmasi RFI/RFQ). Penerima: Direktur Program / User. Sumber angka: seluruh artefak terhitung pada 90_evidence/ (T0_MASTER_TIER0.csv + skrip _calc_*). Langkah rencana kerja: L-14 produksi deliverable.

Riwayat revisi: 0.1 (12-07) kerangka & metodologi; 0.5 (20-07) tujuh dokumen disiplin D1–D7; 0.8 (26-07) konsolidasi matriks fungsi–instrumen & master equipment; 1.0 (26-07) BAB I–XII + Lampiran A–F; 1.1 (26-07) remediasi L-13 menutup 3 temuan KRITIS + 5 MAYOR audit T0-12 (register [UNCERTAIN] 8→10 lini / USD 1.350.400→1.474.400; dasar G-2 dikoreksi 201·15 → 198·18; Uji Tiga Pertanyaan ADD-01…ADD-04; RFI-STD-01; porsi OPEX TCO-10 65,8%; T0-08 → 109 analis / 126 SDM); 1.1-A artefak dibangun ulang pasca-remediasi. Tidak satu pun angka program berubah pada remediasi.

Lingkup kajian (§1.3.2): peralatan analitik & pendukung 202 lini/436 unit; peralatan terikat-bangunan (lemari asam, BSC, casework, gas, exhaust, UPS, genset, keamanan fisik); SW/LIMS/DEMS; OPEX (kalibrasi, uji profisiensi, CRM, kontrak servis); SDM turunan; kerangka standar. Di luar lingkup (§1.3.3): konstruksi sipil (dibahas sebagai persyaratan Bab III, bukan lingkup pengadaan), kapabilitas atribusi eksotik (IRMS/TIMS/MC-ICP-MS/SIMS/nuclear forensics — rujukan keluar kaidah K-9), armada lab bergerak, register biometrik nasional, sintesis/formulasi/kultur peledak-narkotika-bio (batas etis permanen §1.5.6). Program penuh pembanding: USD 361,33 juta termasuk konstruksi; pemangkasan yang sah 87,7% terhadap CAPEX peralatan program penuh USD 176,53 juta, bukan 94,0% (§1.3.4).
