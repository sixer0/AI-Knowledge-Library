# Korpus BUILDING-CONSTRUCTION EKAS - peta sistem bangunan, cara kode berpikir, dan batas pengetahuan (CVLK-0929)

Objek master misi CVLK-0929 (id `building-construction-korpus-ekas-0929`, type catatan, domain
BUILDING-CONSTRUCTION = D3). Muatan = peta rak + angka kunci berpredikat + RANTAI JAMINAN BARU
(Rantai L) mata 1-5 + ambang/norma Indonesia yang TIDAK ada + register known-defect + celah resmi +
batas kemampuan, satu berkas (SATU objek master per domain; bentuk ikut preseden SDCY-0928 + objek
CIVIL-STRUCTURAL + CONSTRUCTION CVLK-0929 seksi 1-8). Provenans: body dirakit dari SATU sumber studi
`research/building-construction-korpus-detail.md` (t_29e82ba9 complete, 320 baris / 35.684 B,
ekstraksi read-only `ekas/`, 2026-09-29); vonis controller LAYAK (D-11) dengan dasar terukur 21/22
anchor navigasi COOK ke PDF primer via pypdf, 0 fabrikasi; guard kode-AS hidup 3 lapis sebelum
studi; celah R1 nol-yang-diangkat; bukti ukur `lib/c3-stu-evidence/` [A]-[E]. Kelas bukti sintesis -
R3 buku berupa PETA NAVIGASI + PRINSIP + PROSES; domain NOL R1/R2/R5 (terukur); yang tidak ada di
rak dinyatakan "tidak ada di rak" beserta sumbernya.

PERNYATAAN BATAS STANDAR (wajib ikut terbit; [R3, resume Codes:8-15; REF-BLD-003:28; ukur [A]
id_code_scan]): korpus ini TIDAK dapat menyatakan kepatuhan bangunan gedung Indonesia. Regulasi
bangunan gedung Indonesia (PP 16/2021 + turunan UU 28/2002 PBG/SLF + SNI teknis bangunan gedung)
TIDAK ADA di rak - keabsenan terukur 0 hit fleet-wide dan dinyatakan sendiri oleh rak ("kosong
yang dinyatakan"). Satu-satunya kode di rak adalah tafsir 2018 International Building Code - KODE
AMERIKA SERIKAT; prinsipnya boleh dipakai sebagai cara kode berpikir dengan label, angka/pasal dan
klaim kepatuhan Indonesia DILARANG (U-1 menunggu nomor final controller). Setiap pemakaian objek
wajib membawa pernyataan ini apa adanya; uji penolakan V-10: satu kalimat pun positif "memenuhi
ketentuan bangunan Indonesia" bersandar rak = FAIL walau rute memori hidup.

Peringatan ketipisan (syarat vonis (e)): domain terkecil di batch - 142 baris resume / 5.429 B
(1.1), 3 PDF primer 164.422.573 B, rasio anchor teruji 21/22; yang terbit = densitas verifikasi +
kejujuran status, bukan ketebalan. Wewenang: PDF hanya dibuka ALAT (pypdf read-only) untuk
meta-navigasi; vonis halaman = vonis LAPISAN TEKS, verifikasi per halaman wewenang manusia
(AGENTS.md; preseden SDCY catatan-2); laci `ekas/` hanya cermin. Tipografi: rak asal memakai
U+00B7/U+2014 + glif peringatan (guard resume Codes:8); objek ini nol keduanya.
