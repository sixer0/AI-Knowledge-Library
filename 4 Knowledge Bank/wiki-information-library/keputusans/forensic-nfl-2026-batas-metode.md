# Empat batas metode yang dinyatakan terbuka (Lampiran D.4)

Empat batas metode dinyatakan agar pembaca berikutnya tidak memperlakukan kajian sebagai jaminan yang lebih luas daripada sebenarnya (Lampiran D.4):
1. Deteksi tumpang tindih bekerja pada nama instrumen, bukan fungsi fisik — dua lini dengan fungsi sama namun penamaan berbeda dapat lolos deteksi otomatis; mitigasi: pola deteksi sengaja sensitif berlebih + pembacaan seluruh 202 lini terhadap register fungsi; keyakinan tidak dapat dinyatakan 100%.
2. Uji kecukupan kapasitas hanya sekuat parameter bebannya — jumlah run per tahun berlabel [ASSUMPTION]; ketika LIMS mencatat utilisasi nyata, seluruh uji kapasitas wajib dihitung ulang.
3. Kajian memeriksa konsistensi keputusan disiplin, bukan kebenarannya — bila disiplin memilih instrumen keliru, konsolidasi tidak menemukannya selama pilihan konsisten; pemeriksaan mutu pilihan = tinjauan sejawat.
4. Verifikasi eksternal tidak dijalankan pada penyusunan Bab X–XII (anggaran kueri web habis) — dua pertanyaan fiskal (RFI-K-01, RFI-K-02) tetap [UNCERTAIN]; nomor standar Lampiran C dicantumkan sebagaimana dirujuk tanpa verifikasi ulang edisi berlaku.
